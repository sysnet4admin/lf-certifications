# 리눅스 재단 자격증 학습 자료

[English](#english)

리눅스 재단(Linux Foundation) 자격증을 준비하면서 정리한 자료입니다. 인프런 강의
[쿠버네티스, MCP 등 자격증 잘 준비하는 법 (CKA, CKS ... MCPA)](https://www.inflearn.com/course/%EA%B3%B5%EC%9D%B8-%EC%BF%A0%EB%B2%84%EB%84%A4%ED%8B%B0%EC%8A%A4-%EA%B4%80%EB%A6%AC%EC%9E%90)의 수업 자료와 함께 사용합니다.

## 자격증별 자료

| 재단 | 자격증 | 자료 |
|---|---|---|
| AAIF | MCPA (Model Context Protocol Associate) | [시험 안내 (슬라이드 PDF)](mcpa/mcpa-guide-ko.pdf), [시험 안내 영상 (YouTube)](https://youtu.be/ZRAaIWi56yo), [용어 치트시트 (한국어, 영어 PDF)](mcpa/cheatsheet/), [예제 시험과 연습 문제](mcpa/) |

CNCF 자격증(KCNA, KCSA, CKA, CKAD, CKS) 자료는 강의 수업 자료로 제공합니다.

## 안내

- 시험 범위의 주요 개념을 개인적으로 정리한 자료이며 출제 내용을 보장하지 않습니다.
- 리눅스 재단과 AAIF(Agentic AI Foundation)의 공식 자료가 아닙니다.
- 이 저장소에서 만든 자료의 라이선스는 [LICENSE](LICENSE)를 따릅니다. 다른 사람이 만든 자료(`mcpa/others-exam/`)는 원작자 폴더마다 있는 LICENSE(MIT)를 따릅니다.
